# Bridge Builder

A variance analysis and bridge (waterfall) builder for finance teams. Name your line items, type or paste the numbers, and the bridge is generated for every perspective at once:

- **This year vs last year** (YoY)
- **Actual vs budget**
- **Quarter over quarter**
- Any **custom view**: pick any two columns (e.g. Forecast vs Budget)

## How to use

1. Open `index.html` in a browser (no install, no server).
2. **Columns**: rename them to your periods (e.g. `Q3 2026 Actual`, `Q3 2025 Actual`, `Q3 2026 Budget`, `Q2 2026 Actual`). Add more with **+ Column**.
3. **Line items**: name each one and choose a type:
   - **Amount**: one number per column. The bridge bar is the change.
   - **Drivers (A×B)**: e.g. `Customers × ARPU` or `Units × Price per unit × Discount factor`. The bridge splits the change into one bar per driver (volume, rate, mix…), which always adds up to the line's total change.
   - **Sign**: `− reduces` for cost lines in a profit/EBITDA bridge.
   - **One-off**: flagged items are shown hatched, and commentary shows the run-rate variance excluding them.
4. **Paste from Excel**: click a cell and paste a block of numbers. Paste rows of `name, values…` into a line-item cell to add many lines at once. Or use **Import Excel / CSV** (first row = column names, first column = line items, a row starting with `Total` becomes the reported total). **Template** downloads the layout.
5. Optional: **Check against a reported total**. Any gap shows up as an *Unexplained* bar so the bridge always ties to the close.
6. Export with **Download Excel** (live formulas: an Inputs sheet plus one bridge sheet per view, with a check row and waterfall helper columns) or **Download PDF** (one page per view: chart, commentary, table).

## Method

Driver lines use sequential substitution. For `Value = A × B × C`:

| Effect | Formula |
|---|---|
| A | (A₁ − A₀) × B₀ × C₀ |
| B | A₁ × (B₁ − B₀) × C₀ |
| C | A₁ × B₁ × (C₁ − C₀) |

The effects sum exactly to `A₁B₁C₁ − A₀B₀C₀`, so the bridge always reconciles.

## Files

- `bridge-builder.html`: the app body (published as a claude.ai artifact).
- `index.html`: standalone version generated by `python3 build.py`. Edit `bridge-builder.html`, then rebuild.

The built-in sample is fictional (an example company), not real figures. Data stays in your browser (saved locally between visits). Nothing is uploaded.
